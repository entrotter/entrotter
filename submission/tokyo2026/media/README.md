# New Tokyo media

The new browser walkthrough is automatically recorded from this repository's UI and measured report.
It is silent with English captions. It is **supplemental**, not a compliant Finalist video: official
Tokyo rules require clear spoken audio and prohibit synthetic/AI voiceover. No voice is fabricated.
The owner delegated prize selection; we chose Uniswap partner prizes only. The Finalist video gate
therefore does not apply to that selected path, subject to the actual submission form.

Recording metadata, duration, checksums and download URL are added after recording and verification.
No old Entrotter/Colosseum footage or artwork is reused.
